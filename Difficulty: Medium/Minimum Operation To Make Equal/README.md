<h2><a href="https://www.geeksforgeeks.org/problems/minimum-operation-to-make-equal/1">Minimum Operation To Make Equal</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">You are given an array <strong>arr[]</strong> consisting of n elements. At each operation you can select any one element and <strong>increase </strong>rest of n-1 elements by 1. Your task is to make all elements equal performing such operation as many times as needed. Find the <strong>minimum </strong>number of operations needed for this.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong style="font-size: 14pt;">Input: </strong><span style="font-size: 14pt;">arr[] = [1, 2, 3]<br></span><strong style="font-size: 14pt;">Output:</strong><span style="font-size: 14pt;"> 3<br></span><strong style="font-size: 14pt;">Explanation:</strong><span style="font-size: 14pt;"><br>Operation 1: Increase all except 3rd, we get 2, 3, 3
Operation 2: Increase all except 3rd, we get 3, 4, 3
Operation 3: Increase all except 2nd, we get 4, 4, 4</span></span></pre>
<pre><span style="font-size: 14pt;"><strong style="font-size: 14pt;">Input: </strong><span style="font-size: 14pt;">arr[] = [4, 3, 4]<br></span><strong style="font-size: 14pt;">Output:</strong><span style="font-size: 14pt;"> 2<br></span><span style="font-size: 18.6667px;"><strong>Explanation</strong></span><strong style="font-size: 14pt;">:</strong><span style="font-size: 14pt;"><span style="font-size: 14pt;"><br></span><span style="font-size: 18.6667px;">Operation 1: Increase all except 3rd, we get 5, 4, 4
Operation 2: Increase all except 1st, we get 5, 5, 5</span></span></span></pre>
<p><span style="font-size: 14pt;"><strong>Constraint:</strong><br>1 ≤ arr.size() ≤ 10<sup>5</sup></span><br><span style="font-size: 14pt;">0 ≤ arr[i] ≤ 10<sup>4</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Greedy</code>&nbsp;
