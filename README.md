## About

This repository is synced automatically with the [GfG To GitHub](https://github.com/AtharvaNanavate/GfG-To-GitHub) browser extension. Every time a solution of mine is accepted on GeeksforGeeks, the problem statement and my code are committed here, sorted into folders by difficulty.

## Repository structure

```
Difficulty: Basic/
Difficulty: Easy/
Difficulty: Medium/
├── Check for BST/
│   ├── README.md          # problem statement, examples, constraints, company and topic tags
│   └── check-for-bst.java # my accepted solution
└── ...
Difficulty: Hard/
```

- Each folder is one problem, named after its GeeksforGeeks title.
- `README.md` holds the full problem statement as shown on GeeksforGeeks, with a link back to the original problem.
- The `.java` file is my accepted solution, written as the `Solution` class that GeeksforGeeks expects.

## How to use

1. Open a difficulty folder, then a problem folder.
2. Read the problem's `README.md`, or follow its link to the original problem on GeeksforGeeks.
3. To run a solution, paste the `.java` code into the matching problem's editor on GeeksforGeeks, or add a `main` method and compile it locally with `javac`.
